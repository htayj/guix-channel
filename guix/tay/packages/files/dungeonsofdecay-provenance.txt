The dependencies directory and prebuilt shared/static/platform libraries are
removed. Only the C object closure from makefiles/makefile-linux64:103-130,
including wrappers.c, is compiled with -fPIC and linked into libtcod.so.
Guix source-built sdl12-compat, libpng and zlib supply the runtime dependencies.

LIBTCOD-LICENSE.txt, LIBTCOD-CREDITS.txt and README-SDL.txt are retained intact.
The historic credits describe upstream's old bundled versions; they do not
assert those binaries are shipped by this package.

WRAPPER BYTE PROVENANCE AND ABI
Game libtcodpy.py is byte-identical to exact libtcod 1.5.0's upstream wrapper:
SHA256 06cabce429a56a389fc7be3dbd79081032504601730b813121ea28a95772b3d1.
Its original Jice BSD notice remains in the installed source and notices.
The package repairs pointer return/argument types for every console/image/map
entry used by the game and its helper modules, using the exact 1.5.0 headers.
TCOD handles are void*, bool is uint8, Color is three uint8 bytes and Key is
an int enum, one char byte and six uint8 booleans, with native alignment.
Key.c remains numeric because original gameplay uses chr(key.c).
Root console 0 and RNG 0 remain NULL handles. Root init takes the original
four arguments; no modern renderer argument is introduced. Color arithmetic
wrapper signatures and all used non-handle functions are declared too.
The private CDLL and four asset references resolve to immutable store paths.
Native repairs only use png_get_channels and NULL for retired libpng internals,
and explicit int arguments for the old SDL ASCII mapper definition.

GAME CURSOR ARGUMENT REPAIR
The original Dungeons_of_Decay.py:1665 and :1669 pass color_light_background
(a Color) as console_put_char's background enum when drawing the '+' look
and 'X' targeting cursors. Their trailing comments identify BKGND_NONE as
the intended argument. The game-portability patch replaces exactly these
two arguments with libtcod.BKGND_NONE and removes the obsolete comments.
Exact 1.5.0 console.h defines NONE as zero; console_c.c leaves the terrain
background unchanged while drawing the glyph and foreground. The strict
ctypes c_int background enum remains unchanged: no Color conversion shim
or invalid packed-color flag is introduced. This patch applies after the
existing source CRLF normalization and wrapper ABI patch.
Main reproduced the original look-cursor failure on 2026-10-11: render_all
at line 1665 raised ctypes.ArgumentError, argument 5 wrong type. The repaired
game's rebuild and native regression verification remain Main's responsibility.

RUNTIME DESIGN
The launcher executes the immutable main file as Python 2 __main__, not an
imported module: native shelve protocol-2 class references therefore retain
the original __main__ names. No game files are copied into writable state.
The working directory is $XDG_DATA_HOME/dungeonsofdecay, defaulting to
$HOME/.local/share/dungeonsofdecay. All native savegame.rls backend suffixes
remain there. Python -B suppresses store bytecode; -s and -E avoid ambient
user-site and interpreter-environment injection. No seeds, forced saves,
smoke modes, input hooks, networking or synthetic game-state contracts are
added. Original gameplay and the ordinary X11/SDL consumer remain intact.
