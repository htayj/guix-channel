DungeonMinder 0.8 terminal.png provenance

The installed share/dungeonminder/terminal.png is the unmodified root
terminal.png from the primary libtcod 1.4.0 source archive:
https://codeload.github.com/libtcod/libtcod/tar.gz/refs/tags/1.4.0
Tag commit: 9ac2a3a526e7cefe8b7b330e37619bb1c4b6fb96
Archive SHA256: cbf7b636b8035b2ac686aa322d35d3b74cb5da8973bbd676796918395fb9d6cb

Font SHA256: 5e9e64246b857dc414bd0acde98820885274483580f751b9b3329b8ee86b82f4
Font size: 3150 bytes; 128 by 128 pixels, 16 by 16 glyphs of 8 by 8 pixels.
Layout: standard ASCII, in columns (historical libtcod flags = 0).

The file is byte-identical to terminal.png shipped in the official
DungeonMinder v0.8 - Linux.tar.bz2 release:
https://storage.googleapis.com/google-code-archive-downloads/v2/code.google.com/dungeonminder/DungeonMinder%20v0.8%20-%20Linux.tar.bz2
Release SHA256: d57e719d33b4dd34fd5e9d18f1d2220510033b2e2bbd09e0106d5e4fd6dc1242
No game or bundled library executable from that release is used in this package.

The primary source's fonts/README.txt identifies the root terminal.png as the
non-antialiased terminal font carried forward from libtcod 1.3.2.  That README
is reproduced as libtcod-fonts-README.txt beside this file.  The distribution's
global permissive notice is reproduced verbatim as LIBTCOD-LICENSE.txt.
No separate font-specific author or license notice was supplied in the primary
source tree; this package does not claim that such a separate grant was found.
The unrelated Celtic Garamond credit is not attributed to terminal.png.

The game uses this immutable installed pathname with the original 1.4.0
setCustomFont(file, 8, 8, 0) API, preserving glyph indices and the original
80 by 60 cell display.  It does not substitute a modern default font.
