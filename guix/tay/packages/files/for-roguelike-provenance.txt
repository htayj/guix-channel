The source's own data and metadata are retained; no replacement assets are used.
The active font's original bytes are preserved; see the complete Bitstream
Vera and Arev notices in for-roguelike-font-license.txt.  Original libtcod font
README and credits are also retained.  Do not treat the complete DejaVu font

installed runtime asset; its independent provenance is not established.

The exact libtcod 1.5.1 C/C++ API comes from the channel's existing source-built
private dwarftown-libtcod recipe, with its BSD-3-Clause library notice,
LodePNG source notices, SDL notice and credits installed alongside this file.
The game bundle's original libtcod license and credits are retained too.
libnoise 1.0.0 and noiseutils are compiled from the bundled source and retain
their LGPL-2.1-or-later notices.  System Guix Boost and Xerces-C supply the
remaining dependencies; vendored SDL, Xerces and platform binaries are not used.
The source snippet explicitly removes the five extensionless libtcod sample/
tool executables, build/osx/FOR/build/Debug/for, and the bundled SDL.framework
tree (including its opaque Mach-O binary and symlinks).  These binaries are
not retained by the prepared Guix source output; no game source is removed.

Packaging changes, 2026-10-19

All actual src/*.cpp files are compiled, rather than the stale upstream Linux
Makefile object list (which requests nonexistent AmmoParser.cpp and other files).
All bundled libnoise model/module sources and noiseutils.cpp are compiled too.
The minimal portability patch supplies the normal Linux main entry point,
corrects two qualified constructor names in new expressions, and fixes the
Path.h include typo Util.h to the existing Utils.h.  No game classes, features
or dormant unfinished interfaces are deleted to simplify compilation.
Only the three immutable runtime asset read paths change: font.png,
data/tileset.cfg and data/items.cfg now use the installed share/for-roguelike
location.  The launcher's working directory is the writable private
XDG_STATE_HOME/for-roguelike (HOME/.local/state/for-roguelike fallback).
No game configurations, seeds, saves or assets are copied/injected into state.
The caller's original directory is not changed or written by the game.

Upstream behavior and limits

The native SDL/libtcod console is 100x60, green on black.  Startup retains
Game::Init's loadDebug=true branch and the time(NULL)-seeded RNG, generating
the original 70x70 Junktown.  Arrows move; Escape quits.  Four native startup
dumps (leveldump.txt, visdump.txt, edgedump.txt, pathdump.txt) remain native
relative outputs in the writable state directory.  Upstream Savefile.cpp's
serialize bodies are empty and its API is not wired to ordinary gameplay:
this package does not claim save/resume.  Creature AI's unfinished main-loop
hook is also unchanged.  "Complete alpha" means all recovered original code,
not an invented finished game.  Native acceptance evidence is recorded in the
channel accounting separately; this notice does not assert a build/test pass.
