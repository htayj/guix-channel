Third-party material in the LiteGraph bundles
=============================================

The litegraph package's build/litegraph.js and build/litegraph.min.js are
concatenated and compiled from this pinned source:
https://github.com/jagenjo/litegraph.js/tree/0555a2f2a3df5d4657593c6d45eb192359888195

The LiteGraph license itself is installed as LICENSE.  The following embedded
shader code has separate copyright holders and notices.

Kuwahara filter: src/nodes/gltextures.js, LGraphTextureKuwaharaFilter
---------------------------------------------------------------------

The upstream comment cites https://www.shadertoy.com/view/MsXSz4.  The same
four-quadrant mean/variance shader appears in an earlier BSD-licensed source,
GPUImageKuwaharaFilter.m.  That file was added to GPUImage on 2012-02-20 in
commit 74b03482ae8322eb6ca61d9173c21d5471c8691b:
https://github.com/BradLarson/GPUImage/blob/master/framework/Source/GPUImageKuwaharaFilter.m

GPUImage attributes the shader to Kyprianidis, J. E., Kang, H., and Doellner,
J., "Anisotropic Kuwahara Filtering on the GPU", GPU Pro, p. 247 (2010).

Omitted inactive code
---------------------

Upstream glfx.js includes an inactive depth-of-field node and shader inside a
block comment.  Its comment cites a Tuxedo Labs/Voxagon blog post, which grants
no license.  The Guix build removes only that comment before concatenation, so
the readable bundle does not redistribute the unlicensed shader.  The compiled
bundle is unaffected, because Closure Compiler drops comments.
