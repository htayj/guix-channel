are retained. tilesetV2.dat credits onionknight, hutze, apostrophest and Crawl
Stone Soup artists. Immortius contributed the orc/terrain sprite integration.

original author's game-wide GPLv3 grant and contribution history support this
scope; no conflicting restrictive grant was established in the review.

ascii-paint/terminal.png (SHA256
5e9e64246b857dc414bd0acde98820885274483580f751b9b3329b8ee86b82f4).
The installed terminal_x2.png, renamed terminal.png by upstream's CMake rule,
is its exact nearest-neighbor double-size version. The included historical
libtcod BSD license preserves the library copyright, conditions and disclaimer.
The historical font README calls its data/fonts collection public domain and
references the old non-antialiased terminal. Its explicit directory scope is
not an exact file-specific public-domain certificate for ascii-paint/terminal;
the general BSD grant and original game grant provide additional evidence.
See goblins-lot-libtcod-1.5.1-LICENSE.txt and
    goblins-lot-libtcod-fonts-README.txt (full original texts).

COPIED CPYTHON ROUTINE
The load_package implementation in game/lib/gcamp/utils.py is copied from
CPython 3.11 Lib/imp.py, with project adaptations. Copyright Python Software
Foundation and earlier Python contributors as detailed in the accompanying
complete goblins-lot-CPython-3.11-LICENSE.txt (including historical agreements).
Upstream modification summary: the copied package-path search is retained;
loading uses importlib.util.spec_from_file_location with an empty submodule
search list, re-executes an existing sys.modules entry when present, otherwise
creates a module, inserts it in sys.modules and executes its loader. This
replaces the removed imp interface for Python 3.12. GNU Guix does not replace
or rewrite that copied implementation.
https://github.com/python/cpython/blob/3.11/Lib/imp.py#L200

Leont/libperl-- -> cbab/libtappp -> dhyannataraj/libtappp. The bundled C++ files
match the latter fork, which omitted the LICENSE referenced by its README.
The original Leont/libtap-- MIT license has been restored as t/libtappp/LICENSE;
see goblins-lot-libtappp-LICENSE.txt. This documents the MIT lineage, not a
new grant on behalf of later contributors. Tests are built/run, not installed
as game executables; no assertions were removed by the packaging.

NATIVE DEPENDENCIES
Boost, Python, SDL2, SDL2_image, Mesa/OpenGL, PNG and zlib are separate Guix
inputs. Private libtcod-goblins-lot 1.23.0 retains the original software renderer
and all other original renderers, threads, compression and Unicode support.
External Guix LodePNG/c, utf8proc, zlib and whole stb replace bundled copies.
The generated GLAD 0.1.28 loader and Khronos header are retained with their
notices. The private library installs its BSD license, credits, full generated
loader/header notices, GLAD MIT license and actual externally compiled stb
header notices in share/doc/libtcod-goblins-lot. Other shared dependencies
retain their own Guix license materials; this is not an assertion that the
whole transitive closure has one license.

PACKAGING MODIFICATIONS
Modified for GNU Guix on 2026-10-21: correct the native XDG directory spelling;
make pixmap installation respect the prefix; install executable in bin and
preserve native executable-relative resource discovery; find external libtcod
dependencies offline and retain their notices; restore omitted source licenses.
Remove only the obsolete compiled Boost.System component requirement:
Boost 1.89 supplies its API header-only, while remaining compiled components
are still required. Capture actual unpacked source roots for original test
fixtures and copyright installation.
Use Python's normal standard-library zlib extension instead of registering
PyInit_zlib as a libpython builtin: Guix's Python builds zlib as a dynamic
extension. Import it during existing bootstrap exception handling using the
unchanged isolated interpreter search path, without wrappers or host fallbacks.
Compression remains enabled; no save/load or scripting code is removed.
Clear a consumed main-menu keyboard callback after it returns. Previously the
selected callback persisted across frames and immediately reopened Settings
or another selected screen after returning, trapping ordinary navigation.
All original screens and keyboard/mouse menu actions remain available.
Remove unused Windows-only opaque binaries from the repacked source:
tools/installer/redists (Microsoft debug DLLs and VC2008/VC2010 installers),
game/crash-reporter/prebuilt (SharpZipLib DLL, crash reporter EXE, debug symbols
and its configuration), and game/crash-reporter/ICSharpCode.SharpZipLib.dll.
Original Windows reporter source and every native game asset remain. This
removal does not assert redistribution rights over Microsoft's binaries; the
unchanged downloaded archive identity is recorded separately by the recipe.
No game resources, rendering modes, game rules, native state-generation code
or reproducible upstream 0.25dev version metadata are replaced or removed.
