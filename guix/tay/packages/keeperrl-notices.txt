Package integration changes
---------------------------
The no-Steam input implementation reports the absence of Steam controllers;
SDL keyboard/mouse input remains native. Upstream unit tests remain compiled
in the release build, without developer quick-game controls. DejaVu font
paths replace upstream contrib font paths. The unconditional personal-message
download is removed. Online exchange/game-event reporting defaults are off,
and the launcher disables crash reporting. Online exchange remains a user
opt-in. Version/date generation is fixed to the pinned source revision.
Equipment scoring includes the creature attack baseline independently of the
item modifier map, fixing a negative DAMAGE modifier incorrectly making a Bow
more valuable. The existing upstream equipment regression test is unchanged.
The obsolete testDungeonLevel numeric balance snapshot is removed, not re-pinned.
Upstream commit 6d905cc29f5e10a96ff4e4205d4d0cf86ddd3d0a (2022-12-08) intentionally
reduced lesser/main villain rewards from 11/25 to 6/12. Production balance
is unchanged; the remaining native upstream suite runs in the release build.
https://github.com/miki151/keeperrl/commit/6d905cc29f5e10a96ff4e4205d4d0cf86ddd3d0a
