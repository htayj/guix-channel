The fonts are redistributed unmodified, bundled with the game software, as
permitted by OFL 1.1 section 2.

Not installed: the upstream package/ directory (installer icon, AppImage,
macOS and NSIS packaging, Quicklisp build script), the README cover art
("Digital drawing images 1", CC-BY 3.0) and the Tango icons.  No prebuilt
executables or bundled shared libraries are used: Allegro, the Allegro
Nuklear bridge and every Common Lisp library are built from source by Guix
and loaded from their own store paths.  Their notices are installed by the
respective packages.

The game has no save files, no network features and no updater.  It reads
an optional config.cfg next to Resources/ (inside the store, not shipped)
and writes nothing.
