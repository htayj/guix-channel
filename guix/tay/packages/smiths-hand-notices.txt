The Smith's Hand: installed source and asset closure
==================================================

Snapshot version: 2014-03-16 (upstream archive Last-Modified date).

Room map
--------
rooms/village.map is the original map. LICENSE.TXT explicitly declares
.map files public domain.

Font
----
terminal.png is the original libtcod 1.3.2 legacy terminal bitmap, identical
in the archive's linux/ and lib/libtcod-1.5.0/ directories. Its SHA-256 is
5e9e64246b857dc414bd0acde98820885274483580f751b9b3329b8ee86b82f4.
FONT-NOTICE.txt reproduces libtcod's public-domain font declaration and its
explicit reference to the legacy terminal.png font. No other fonts ship.

Rendering library
-----------------
libtcod 1.5.0: Copyright (c) 2008,2009,2010 Jice. Three-clause BSD terms
are reproduced in LIBTCOD-LICENSE.txt. LIBTCOD-CREDITS.txt and README-SDL.txt
are retained. The private libtcod archive is rebuilt from the source included
in the same pinned origin; no upstream executable or shared library is reused.
SDL 1.2 compatibility, libpng and zlib are dynamic Guix dependencies, not
copies of bundled binary libraries. Their packages provide their sources
and licenses. The GNU build system supplies compiler and make tooling.

Runtime data and exclusions
---------------------------
The original smith.cfg is installed with music.enable false and screen.full
false. All other original configuration values, game text and map remain.
Upstream main.cpp disables USE_AUDIO, so its unused SDL_mixer Makefile link
flag introduces no audio dependency. The archive's empty music directory,
platform executables, Microsoft runtime DLLs, bundled SDL/libtcod binaries,
demo programs, sample data and other fonts are not installed. There are no
runtime downloads. Save files and copied caller configuration are writable
only in the caller's XDG data directory; immutable assets link to the store.
The original Q command saves; the original loader consumes smith.sav on
startup. Native saves use the upstream host-endian serialization format;
no cross-architecture save compatibility is promised.
